# 🤖 Intern Onboarding Chatbot

## 📌 Overview
The Intern Onboarding Chatbot is a Streamlit-based application designed to support interns during their onboarding process. It reduces repetitive questions to managers and supervisors by providing instant answers to common queries related to HR processes, ICT support, internship procedures, and office guidelines.

---

## 🚀 Features
- 💬 Chatbot for answering intern FAQs  
- 📂 FAQ-based response system using a CSV dataset  
- 🔄 Option to clear/reset user questions  
- 📊 Manager dashboard to monitor usage and performance  
- ☁️ Deployed on Streamlit Cloud for easy access  

---

## 🛠️ Tech Stack
- Python  
- Streamlit  
- Pandas  
- CSV (FAQ dataset)  
- Streamlit Cloud (Deployment)

## ⚙️ How It Works
- Intern enters a question in the chatbot interface  
- The system matches the query with the FAQ dataset  
- The most relevant answer is returned instantly  
- Managers can view usage insights through the dashboard  

---

## 🌐 Deployment
The chatbot is deployed using Streamlit Cloud, allowing interns to access and test the system online.

---

## 🎯 Project Objective
The chatbot was developed to support the onboarding process by reducing onboarding time and helping interns easily access information during their early stages in the organisation. It provides a simple way for interns to ask questions without needing to approach busy managers or supervisors, ensuring quick access to support and guidance when needed.
